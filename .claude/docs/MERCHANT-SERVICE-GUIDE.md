## 💰 **SERVICE PURCHASING SYSTEM**

### **📱 SMS Marketing Service**

#### **How Merchants Purchase SMS Credits**
1. **Login to Dashboard** → Go to "Marketing" → "SMS Credits"
2. **Choose Package**:
   - **Starter**: 100 SMS for Rs 200 (Rs 2/SMS)
   - **Popular**: 500 SMS for Rs 900 (Rs 1.80/SMS) 
   - **Business**: 1,000 SMS for Rs 1,700 (Rs 1.70/SMS)
   - **Enterprise**: 5,000 SMS for Rs 7,500 (Rs 1.50/SMS)
3. **Payment Options**: eSewa, Khalti, IME Pay, Bank Transfer
4. **Auto-renewal**: Optional monthly credit top-up

#### **SMS Usage Scenarios**
```
✅ Order Confirmation: "Hello John, your order #12345 is confirmed. Total: Rs 2,500"
✅ Shipping Update: "Your order #12345 has been shipped. Track: ABC123"
✅ Delivery Confirmation: "Your order #12345 delivered successfully. Thank you!"
✅ Promotional: "Special offer! 20% off on Electronics. Expires: Dec 31"
✅ Birthday Wish: "Happy Birthday! Get 15% off on your next purchase"
✅ Abandoned Cart: "You left items in cart. Complete your purchase now!"
```

#### **SMS Template Management**
- **Pre-built Templates**: 20+ ready-to-use templates
- **Custom Templates**: Create your own in Nepali/English
- **Variable Support**: {customer_name}, {order_id}, {total_amount}
- **A/B Testing**: Test different message versions

## 🔌 **THIRD-PARTY INTEGRATIONS**

### **🚚 Logistics Integrations**

#### **Pathao Integration**
**Setup Process**:
1. **Get Pathao API Key** → Contact Pathao Business Team
2. **Configure in Dashboard** → Go to "Integrations" → "Pathao"
3. **Enter API Credentials** → API Key, Secret Key
4. **Test Connection** → Send test delivery request
5. **Go Live** → Start processing real orders

**Features**:
- **Same-day Delivery**: Within Kathmandu Valley
- **Real-time Tracking**: Live delivery updates
- **Automatic Label Generation**: Print shipping labels
- **Delivery Confirmation**: Photo proof of delivery

**Pricing**: Pathao's standard rates (we don't charge extra)

## 💡 **BEST PRACTICES FOR MERCHANTS**

### **SMS Marketing Best Practices**
1. **Timing**: Send SMS between 9 AM - 8 PM
2. **Frequency**: Don't send more than 2 SMS per week
3. **Content**: Keep messages short and clear
4. **Personalization**: Use customer names and order details
5. **Opt-out**: Always include unsubscribe option

### **Email Marketing Best Practices**
1. **Subject Lines**: Make them compelling and clear
2. **Mobile-Friendly**: Ensure emails look good on mobile
3. **Segmentation**: Send relevant content to different customer groups
4. **Frequency**: Don't overwhelm customers with too many emails
5. **Analytics**: Track open rates and click rates

### **Integration Best Practices**
1. **Test First**: Always test integrations before going live
2. **Monitor Performance**: Check integration status regularly
3. **Backup Plans**: Have alternative shipping options
4. **Customer Communication**: Keep customers informed about delivery updates
5. **Analytics**: Use analytics to optimize your marketing
