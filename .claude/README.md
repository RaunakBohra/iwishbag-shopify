```bash

```
1. @PM creates task in .claude/tasks/active/
2. @Architect designs and creates spec in .claude/docs/specs/

## Critical Rules

### Multi-Tenancy (HIGHEST PRIORITY)
- ✅ All queries MUST filter by tenant_id
- ✅ PostgreSQL RLS policies MUST be enabled
- ✅ Test with 2+ tenants ALWAYS
- ❌ NEVER expose tenant_id in URLs
- ❌ NEVER allow cross-tenant data access

### Database Safety
- ❌ NEVER reset database (1000+ tenants)
- ❌ NEVER delete data without backup
- ✅ ALWAYS use safe migrations
- ✅ ALWAYS test on staging first

### Code Quality
- ✅ TypeScript strict mode
- ✅ Error handling
- ✅ Bilingual support (EN/NE)
- ✅ Indigo/pink theme (no teal/amber)
- ✅ File size guidelines (200-500 lines)

### Nepal-First
- ✅ eSewa, Khalti, IME Pay payments
- ✅ Pathao, Tootle logistics
- ✅ Sparrow SMS
- ✅ NPR currency (रू)
- ✅ Nepali language (Devanagari)
- ✅ Nepal timezone (UTC+5:45)

```
1. "@QA, test orders API for tenant isolation"

```

## Project Context

**Project**: Nepal E-Commerce Platform (iWishBag) - Nepal's first affordable Shopify alternative

**Goal**: 1,000 merchants @ Rs 1,999-4,999/month in 18 months

**Features**: 145 features across 24 sprints

**Tech Stack**: Next.js 15, Hono, Neon PostgreSQL (shared DB), Cloudflare

**Unique Value**: Nepal payments, Nepal logistics, Nepali language, affordable pricing

**Architecture**: Multi-tenant SaaS with single shared database + RLS

**Cost Target**: $15-1,058/month (0-1000 merchants)

**Revenue Target**: Rs 15,59,400/month at 600 paying merchants
